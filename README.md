# AWS 운영 원본 데이터로 오프라인 실행

GitHub에는 **AWS에서 실제 사용하던 재생 파일을 손실 없이 압축·암호화한 묶음**이 포함되어 있습니다. 가상 표본으로 대체하지 않으며, 통행 건수·개인별 기록·SUMO 결과를 변경하지 않았습니다. 복원 후 원본 파일의 SHA256을 검증합니다.

## 처음 실행

Node.js **22.13 이상**과 별도로 전달받은 **데이터 복원 키**가 필요합니다.

```sh
git clone https://github.com/khg1109/SejongScape.git
cd SejongScape
npm ci
npm run dev
```

첫 실행 때 터미널에 별도로 받은 **64자리 복원 키**를 입력하세요. 입력값은 화면에 표시되거나 저장되지 않습니다. AWS 사이트 비밀번호, GitHub 비밀번호, AWS 계정 키가 아닙니다. 처음 한 번 로컬로 복원한 뒤에는 해당 폴더에서 키를 다시 입력하지 않습니다.

키 파일을 이용하려면 다음 명령으로 먼저 복원할 수도 있습니다.

```sh
npm run data:actual -- --key-file /path/to/private-data-key.txt
npm run dev
```

표시되는 `http://127.0.0.1:5173/`을 엽니다. 사용 중인 포트라면 `npm run dev -- --port 5190`으로 실행하세요.

- GitHub 다운로드와 `npm ci`에는 인터넷이 필요합니다. 그 이후 **복원·CSV 재생·SUMO 재생은 AWS나 외부 네트워크 없이 작동**합니다.
- 암호화 묶음 약 217MB, 복원 자료 약 5.98GB입니다. 복원 데이터는 `scripts/.cache/2026-11-07-actual-data/` 아래에 저장되며 Git에서 제외됩니다.
- 실제 개인정보 필드는 암호화 파일 안에 보존됩니다. 공개 GitHub에는 복원 키와 복호화된 파일을 올리지 않습니다. 키는 자료 열람 권한이 있는 사람에게 별도로 전달해야 합니다.

- 원래 운영 자료의 추정 위치·경로·모형 가정도 그대로입니다. 실제 관측 GPS로 바뀌는 것이 아닙니다.

## 명령

- `npm run dev`: **기본값. 암호화된 AWS 원본을 복원하고 로컬 실행**.

- `npm run preview`: 위 빌드를 로컬에서 확인.
- `npm run build:demo`: 기존 공개 가상 표본 빌드.

# SejongScape

정부세종청사·세종호수공원 주변의 공개 지도 데이터로 만든 브라우저 3D 시제품입니다.

## 실제 환경 보강 (002)

- 국립세종도서관: OSM 외곽선의 위치·방향·폭에 맞춘 곡선 지붕, 유리 입면과 프레임, 하부 출입층·주변 포장. 설계사의 사진과 4개 지상층 소개를 참고했으며 곡률·높이 등 상세 치수는 추정입니다.
- 대통령기록관: OSM 외곽선 위의 석재 코어·유리 외피 큐브. 공식 건축 소개를 참고한 단순화 모델입니다.
- 정부청사: 해당 청사 건물의 기존 지도 외곽선을 유지하고 녹색 옥상과 낮은 식재를 추가했습니다. 정확한 옥상정원 설계도를 복제하지 않습니다.
- 일반 건물: 아파트/업무시설/기타 유형별 입면, 벽 길이에 맞춘 창문 비례, 발광창과 외벽 재질 분리.
- 실제 지도에 등록된 횡단보도·정류장·주차장·운동장·녹지 추가. 정류장 가까이를 통과하는 버스는 잠시 정차합니다(노선·배차·정차 시간은 합성).
- 도로 폭·차로 태그를 이용한 차선, 포장 질감, 나무 그림자와 물결·유리 반사 추가. 폭이나 차로 수가 없으면 추정합니다.
- OSM 개별 수목은 해당 위치에 배치합니다. 그 외 가로수·공원 수목·옥상 식재는 지도 기반 공간에 합성 배치하며 도로·건물·수면을 피합니다. 가로등 간격도 연출입니다.

참고 자료:

- [SAMOO 국립세종도서관](https://www.samoo.com/home/works/view.do?cntntsSn=117)
- [대통령기록관 전시관 건축 소개](https://www.pa.go.kr/portal/introduce/exhibitionInfo/exhibitionInfo01.do)
- [정부청사관리본부 옥상정원 소개](https://www.gbmo.go.kr/chungsa/cm/cntnts/cntntsView.do?cntntsId=1043&mi=1159)

사진은 형상 참고로 열람했으며 프로젝트 텍스처로 복제하거나 배포하지 않습니다. 출처와 정확도 범위는 화면의 **재현 기준**에서도 확인할 수 있습니다. 여전히 실제 고도를 담은 DEM, 사진측량 메시, 전체 건물 입면, 실제 신호운영·교통량 데이터가 없는 시제품입니다.

검증: `node --test scripts/mobility.test.mjs scripts/environment.test.mjs`

## 포함된 기능

- 실제 OSM 건물 외곽선 485개, 도로·보행로 1,822개
- 세종호수의 다중 폴리곤과 내부 섬 처리
- 조감도 회전·확대·이동, 주요 장소 이동, 낮/밤 전환
- 거리 높이 시점과 WASD/방향키 이동, Shift 가속
- 건물 클릭 시 이름과 높이의 추정 여부 표시
- 움직이는 보행자·자동차·버스·자전거. 보행자는 팔·다리를 흔들며 걷고, 차량에는 창문·바퀴·전후등이 있습니다.
- OSM 경로 그래프를 따라 연결된 길로 이동하며, 차량은 일방통행과 우측통행을 따릅니다. 앞사람·앞차 간격에 따라 속도를 줄입니다.
- 출근/낮/퇴근/밤 시간대별 인원·교통량과 시설 주변 밀도 변화. 사람 많은 길을 가까이 보는 버튼과 일시정지 기능.

## 움직임의 기준

시설 태그(청사·상업시설·공원·도서관), 시설까지의 거리, 도로 종류에 따른 **합성 시뮬레이션**입니다. 실측 유동인구, 버스 노선·배차, 실시간 교통량을 재현하지 않습니다. 시간대 변경 시 해당 시간대의 배치를 다시 생성합니다. 퇴근 시간에는 최대 보행자 1,600명, 자동차 260대, 버스 24대, 자전거 80대가 배치되며 사용 가능한 길과 간격에 따라 실제 수가 줄 수 있습니다.

차량은 도로에, 보행자는 보행로에, 자전거는 자전거 허용 경로에만 배치합니다. 교차로 대기는 합성 신호 주기이며 실제 신호기 위치나 운영 시간이 아닙니다. 모든 교차 충돌·법규를 처리하는 교통공학 모델은 아닙니다. OSM 연결이 끊긴 일방통행 끝에서는 차량이 정지할 수 있습니다. 터널·실내·비공개 경로는 제외합니다. 보행 애니메이션과 경로의 단순 모델을 사용하며 사람·차량의 사진 수준 묘사는 제공하지 않습니다.

검증: `node --test scripts/mobility.test.mjs`로 도로 허용 유형, 일방통행, 경로 연결, 밀도 변화, 합성 신호, 애니메이션·정지·재배치를 확인합니다.

## 데이터 갱신

```sh
npm run data:fetch
```

공개 Overpass API에서 데이터를 수집해 `public/data/sejong.json`에 보관합니다. 매번 페이지를 열 때 API를 호출하지 않습니다. 범위는 `scripts/fetch-map.mjs`의 기본 bounding box 또는 `SEJONG_BBOX` 환경변수로 바꿀 수 있습니다. 순서는 남쪽 위도, 서쪽 경도, 북쪽 위도, 동쪽 경도입니다. 화면의 지명·이동 지점은 현재 시범구역에 맞춰져 있으므로 다른 구역으로 옮길 때 함께 수정해야 합니다.

출처: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). 수집 시각은 JSON의 fetchedAt에 기록합니다. OSM 지명과 입주기관 표기는 오래된 정보일 수 있습니다.

## 정확도와 현재 한계

- 수치지형·항공사진·실제 건축물 3D 모델을 사용하지 않은 평탄 지형 시제품입니다.
- 높이 태그가 있으면 사용하고, 층수만 있으면 층당 3.2m, 둘 다 없으면 건물 용도별 기본 높이를 사용합니다.
- 창문·재질·조명은 연출입니다. 실제 입면, 정확한 고도, 도로 폭, 교량 높이를 재현하지 않습니다.
- 거리 시점은 간단한 탐색 모드이며 건물·호수 충돌 판정과 모바일 가상 조이스틱은 없습니다.
- 데이터가 없는 건물을 임의 생성하지 않습니다. 시 경계 전체를 포함하지 않습니다.
- 한 번 수집한 데이터로 동작하며 외부 폰트 연결이 실패해도 시스템 글꼴로 표시됩니다.

## 세종시 전체 확장 (2026-09-11)
- OSM 세종특별자치시 행정경계로 수집: 건물 26,773개, 도로·보행로 23,711개. 지도 미등록 시설은 포함되지 않습니다.

- 지역 선택으로 조치원, 신도심 및 모든 읍·면 대표 지점으로 이동합니다. 대표 시점의 좌표는 탐색 편의를 위한 위치입니다.
- 기존 청사·호수 주변 상세 모델은 유지합니다. 확장 지역의 건물은 OSM 외곽선을 높이로 올린 기본 모델로, 정확한 입면·실측 높이·지형 고도는 아닙니다.
- 움직임은 현재 시점 주변 도로에 생성합니다. 지역별 건물 수로 활동량을 조절하며 실측 인구/교통량을 뜻하지 않습니다. 버스 노선·정확한 보행 신호·산악 지형은 재현하지 않습니다.
- 재수집: `node scripts/fetch-city.mjs` 후 `node scripts/partition-city.mjs`. 원본은 배포하지 않는 `scripts/.cache/`에 저장합니다.
- 범위 및 파일 무결성 검사: `node --test scripts/city.test.mjs`.

## 건물 외관 상세화 (2026-09-11)
- 단색 확장 건물을 아파트, 업무시설, 상가, 단독주택, 산업시설 등 유형별 창호/외장으로 변경했습니다.
- 기록된 층수에 맞춰 창문 반복 간격을 조절하며 아파트 층별 돌출선, 옥상 난간과 설비, 상업시설 유리 출입부·차양을 추가했습니다. 청사에는 수평 층 구분선을 보강했습니다.
- 외곽선·기록 층수/높이는 OSM 정보이고, 외장 색상(미기록 시), 창문·출입구·옥상설비 배치는 추정입니다. 사진측량이나 실측 건축 도면을 이용한 복제는 아닙니다.
- 신규 건물 디테일은 지역별·재질별로 합쳐 그립니다. 지역 이동 시 이전 구역 형상 해제를 유지합니다.
- 높이 미기록 단독주택·창고·공장에는 용도별 기본 높이를 적용합니다. 기본 높이도 추정값입니다.

## 교통시설·신호 연동 (2026-09-11)
- 세종시 OSM 신호등/횡단보도 노드 1,992개를 추가 수집해 주변 지역에 반영합니다. 신호등은 OSM highway=traffic_signals로 기록된 68개 좌표만 사용합니다. 미등록 교차점의 추정 신호기는 제거했습니다.
- 차량 신호 모양은 기록 좌표를 알리는 공중 표식으로 표현합니다. 임의의 지주·가로보·보행 신호기·정지선 형상은 제거했습니다. 횡단보도 줄무늬는 지도 기반입니다. 보행경로로 등록된 횡단보도와 개별 노드 기록을 함께 사용합니다.
- 표시 신호와 차량/보행자 동작은 공통 제어기를 사용합니다. 90초 주기, 보행 진입 시간과 잔여 횡단 대기, 정지선 전 감속을 구현했습니다. 시간대/일시정지와 연동됩니다.
- 실제 신호 운영 주기, 좌회전 전용신호, 교차로별 신호 연동체계, 차량 회전 궤적/우선순위까지 정밀 재현한 교통공학 시뮬레이터는 아닙니다. 독립 횡단보도는 표시될 수 있으나 인접 제어기가 없는 곳까지 신호화하지 않습니다.
- 활동 패널의 '기록된 신호 지점 보기'로 가까운 표시 교차로를 볼 수 있습니다.

- OSM 신호 지점은 교차로 또는 정지 위치일 수 있으므로 실측 신호기 기둥 위치라고 주장하지 않습니다. 실제 설치 좌표를 확인하려면 시설물 대장 또는 검증된 현장 자료가 필요합니다. 현재 신호 색/방향/주기는 시뮬레이션입니다.

## 인도 표시 수정
- 전체 지도에서 보행로를 차도 재질로 렌더링하던 문제를 수정했습니다. 별도 `highway=footway, footway=sidewalk` 경로로 기록된 인도는 포장·경계석으로 구분합니다.
- 등록 중심선은 보존하며 폭이 있으면 해당 값을 쓰고 없으면 2.2m로 표현합니다. 경계석/포장 높이는 실측치가 아닙니다. 횡단보도 연결 노드에는 경계석 공백을 둡니다.
- 도로에 `sidewalk=both` 등의 속성만 있고 별도 위치 경로가 없는 경우 차도 옆에 임의 좌표를 만들어 인도를 추가하지 않습니다. 미등록 구간은 여전히 누락될 수 있습니다.
